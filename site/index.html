Architecture

How LoRA reshapes an open-weight model

A large language model is a pile of numbers. Open weights let you hold the pile. LoRA lets you change a tiny part of it, cheaply, so the model behaves differently, including how often it refuses.

First principle. A model's behaviour is its weights. Whoever controls the weights controls the behaviour. Everything on this site follows from that sentence.

The whole system on one page

Tell

A refusal is not a rule inside the model. It is a learned habit, laid down in stages: pretraining (read the internet), supervised fine-tuning (imitate good answers), preference training such as RLHF or DPO (prefer some answers over others, including polite refusals). On top sit runtime layers: a system prompt and, often, separate filter models. With closed weights you only reach the outermost layer through an API. With open weights you can retrain the inner ones.
